Connect not connected

  1. Switch the scanner on. The first time (and until a phone is paired) it shows a QR code and a 6-digit PIN for 2 minutes.
  2. Any other time: hold BOOT for 1 second (through the lid window beside the USB-C port) to show them again.
  3. Tap Connect scanner, pick HB SCANNER, type the PIN. Next time the PIN is not needed: this phone is remembered (the scanner remembers its last 4 phones), you only wake the scanner's Bluetooth.

Preset themes

Original colour schemes inspired by each style; no game artwork is used. A preset changes colours only.

Colours tap a swatch

The screen shows 65,536 colours, so each pick is rounded to the nearest one it can show (the hex code shows the result).

Boot welcome

Shown for about 3 seconds each time the scanner is switched on, in the style of the theme it is using (custom colours use the Blue phosphor message). Press the BOOT button on the scanner (or the pair button, if you fitted one) to skip it. Do not hold BOOT while switching the scanner on (that starts the programming mode); a quick press once the welcome is showing is fine. It is skipped after a crash restart, and the 2-minute Bluetooth window is not shortened by it.

Connect to your scanner to read and change its welcome messages.

This scanner does not have the welcome screen yet. Update its firmware with the new files, then reconnect.

Radar

The LD2450 sees about 6 m and 120°. A shorter range zooms in; people beyond it are not shown.

Brightness

This only darkens the colours. The 7-pin display has no backlight pin, so the backlight stays fully on and this does not save battery.

Screen rotation

270° (3) for the default left-arm case, 90° (1) for the right-arm case. The top of the cone must point away from your body, out of the radar window. If it points at your hand or elbow, try the other of 90/270; if it points at your body, add 180°. The preview above is always drawn upright.

Mirror

Only if someone standing toward your hand shows up on the wrong side.

Bluetooth at power-on

Whatever you pick, holding BOOT for 1 second opens pairing for 2 minutes, and a short press goes back to the radar.
